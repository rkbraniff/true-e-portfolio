# 🔐 Encrypted Chat App

A real-time messaging system with end-to-end encryption, forged in React and Node.js.

## 🛠 Tech Stack

- React + Tailwind UI
- Node.js + Express
- WebSocket Protocol (Socket.io)
- AES-256 symmetric encryption

## 🚨 Features

- Anonymous messaging with client-side encryption
- No message history stored on the server
- Auth-free, ephemeral chat rooms

## 🔓 Security Focus

Messages are encrypted in the browser and decrypted only on the receiving end. Even the server can't read them.

## 🧪 Future Ideas

- Peer-to-peer fallback
- Burner link sharing
