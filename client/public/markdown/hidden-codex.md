# 📜 Hidden Codex

This portfolio is powered by a dynamic CMS and a custom Markdown engine.

## 💡 Architecture

- JSON + Markdown combo system
- Dynamic route handling via React Router
- TailwindCSS for expressive design

## ✍️ Editor Support

Markdown content is managed in `.md` files and supports:

- Headings, lists, images
- Code blocks
- Future support for frontmatter metadata

## ⚔️ Goal

Make content modular and scalable, with no need to hardcode UI data.
